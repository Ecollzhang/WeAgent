# 项目文件夹总结

## `backend/`

后端承担 API、数据模型、服务层、orchestrator、sandbox host 管理和 capability runtime 投影。虽然本包不打包完整源码，但文档记录显示后端是 Agent、message、conversation、capability、toolset、provider config 和 sandbox runtime 的核心承载层。

## `frontend/`

Web 前端承担 WeAgent 的主要浏览器体验，包括聊天、Agent 管理、设置、Toolset/Capability Library、Sandbox Test 和产物展示。Toolset 分支中大量 UI contract tests 和 build 记录说明 Web 前端是 capability 管理的首个完整入口。

## `clients/desktop/`

桌面端是 Electron + Vue 客户端。Phase 04 记录显示它新增了 `/tools` route、桌面 Toolset 页面、Agent capability binding 和一套桌面 API wrapper。桌面端只负责展示、选择、保存和触发会话，不直接执行 npx、MCP、Docker、脚本或 Tool。

## `docs/tech/`

技术方案文档入口，包含问题范围、总体架构、模块索引、API、数据库、事件协议、demo 脚本和风险兜底。它是项目面向技术解释和答辩的基础材料。

## `docs/report/`

阶段性报告目录，记录 Agent Adapter 前端测试、Conversation Context debug、Provider Runtime 方案、Sandbox Service Proxy、Sandbox Agent Adapter Merge 等内容。它们适合证明 AI 协作过程中的调试、设计取舍和合并策略。

## `docs/ai-collab/`

AI 协作归档目录，是本包最关键的证据来源之一。它定义 archive schema、成员 registry、session/archive/summary/spec/skill/rules 的结构，并保存多轮协作记录。

## `.planning/`

GSD 式规划目录，记录项目当前状态、需求、路线图、阶段计划、SPEC、VERIFY、checkpoint、UAT 和 handoff。它是“AI 协作如何进入工程管理”的主线材料。

## `.planning/tmp`

临时验证证据目录。本包只筛选其中的有效证据：截图、日志和 UAT JSON，不打包浏览器 profile/cache。

## `toolset/`

Toolset UAT fixtures 和示例 Skill 目录。它包含 Markdown Skill、bundle review skill、MCP manifest、npx import sources 和命令边界说明，是 Skill/Tool/MCP/Plugin 体系的可展示样例。

## `.claude/`

本地 Claude/AI 工具权限配置目录。本包只保留脱敏副本，用于说明 AI 协作开发中曾配置过读文件、Docker、curl、构建和容器操作等权限。

## `ai-dev-record-package/`

本次新建的交付包目录。它聚合记录、生成解读文档，并最终压缩为 zip，供提交、答辩或归档使用。
