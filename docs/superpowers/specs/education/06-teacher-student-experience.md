# Education 教师端与学生端体验

## 1. 体验原则

- 功能围绕课程和课时，不围绕聊天窗口组织。
- Agent 协作可见，但不要求用户理解底层 provider。
- 所有 AI 内容可编辑。
- 教师始终知道哪些内容尚未发布。
- 学生始终知道内容来源和反馈状态。
- 失败、fallback 和旧版本状态不能被隐藏。

## 2. 教师端导航

复用现有占位菜单并实现：

- 课程
- 作业
- 学生
- 成绩/学情
- 资源

课程内二级导航：

- 概览
- 单元与课时
- 成员
- 课程资料库
- 作业
- 学情
- 工作流模板
- 设置

## 3. 创建课程

教师步骤：

1. 输入课程名称。
2. 选择学科和年级。
3. 绑定 SubjectPackVersion。
4. 选择或跳过 Unit 结构。
5. 获取邀请码/邀请链接。
6. 上传初始课程资料。

创建后默认：

- course status 为 draft。
- teacher membership active。
- 学生不能看到任何未发布内容。

## 4. 课时工作台

统一工作台标签：

```text
教学设计 | 资料 | 讲义 | 课件 | 习题 | 发布
```

### 4.1 教学设计

- 上传或选择课文。
- 输入课时、班级和教师目标。
- 查看 Agent 推荐的主题、文本类型和课型。
- 教师确认分类。
- 选择系统/个人/课程工作流。
- 生成和编辑结构化教案。
- 查看目标—活动—评价校验。
- 导出 DOCX/HTML/PDF。

### 4.2 资料

- 课程 RAG 资料。
- SearchProvider 搜索候选。
- 显示 title、URL、snippet、provider。
- 教师选择后再 fetch 正文。
- 显示 full/partial/snippet-only 状态。
- 选择引用或排除来源。

### 4.3 讲义

- Tiptap 编辑。
- 引用、词汇/生字、提示、问题等教育节点。
- Agent 局部重写。
- 版本比较。

### 4.4 课件

- SlideDocument 页面列表。
- HTML 预览。
- 页面级编辑和局部重新生成。
- PPTX 导出。
- 显示课件基于的教案版本。

### 4.5 习题

- 题型和知识点过滤。
- 题目编辑。
- 答案/解析教师私有视图。
- rubric。
- 预估难度明确标记来源。

### 4.6 发布

发布检查清单：

- 当前教案版本。
- 讲义/课件版本。
- 作业和题目。
- 学生可见范围。
- 答案泄漏检测。
- 外部引用状态。
- Artifact 可用性。

教师确认后生成不可变版本。

## 5. Agent 协作面板

显示任务图或时间线：

- 节点名称。
- Agent。
- pending/running/done/failed/skipped/approval。
- 输入版本。
- 产物。
- fallback。
- 重试。
- 教师审批。

示例：

```text
课程设计 Agent       教案 v3 已完成
资料研究 Worker       4 个来源，1 个 snippet-only
课件制作 Agent       HTML 已完成，PPTX 生成中
习题生成 Agent       8 道题等待审校
教学审校 Worker       发现 2 道题答案依据不足
教师确认              等待处理
```

不展示原始思维链、系统 Prompt 和 secret。

## 6. 自建工作流

复用现有工作流图体验，增加：

- 系统/个人/课程模板库。
- Agent/动作节点选择器。
- required approval gate。
- DAG 校验。
- capability/权限提示。
- 版本和复制。
- 服务端保存。

保存前检查：

- 节点 ID 唯一。
- 不存在循环。
- 所有 Agent 在教育 workspace 可用。
- 所有 capability 已配置。
- required gate 未被删除。
- 并发数和节点数不超限。

## 9. Tutor

默认：

- 只访问 `course_published` + 本人 `student_private`。
- 不直接给出进行中作业答案。
- 优先提示、提问、定位课程资料。
- 引用可点击回源。

教师开启联网拓展后：

- 明确显示“联网拓展”。
- 遵循 Search → Fetch → Retrieve。
- 不允许学生直接选择任意危险 URL 抓取。

## 10. 作业与写作

### 10.1 客观题

- 即时保存。
- 符合教师策略时即时反馈。
- 提交后规则判分。

### 10.2 写作

- Tiptap/结构化文本编辑。
- 自动保存。
- Harper 或语文规则候选。
- 建议逐条接受/拒绝。
- 提交生成不可变 SubmissionVersion。
- 教师反馈后允许一次或教师配置次数的修订。
- 显示版本差异。

## 11. 学习规划

输入：

- 诊断题。
- 当前知识点表现。
- 作业截止时间。
- 教师目标。
- 学生可用时间。

输出：

- 每日/每周任务。
- 预计时长。
- 关联课程内容。
- 完成状态。
- 调整原因。

MVP 使用透明规则调整，不宣称长期最优路径。

## 12. 笔记整理

支持：

- 粘贴/上传零散笔记。
- 选择课程资料。
- 结构化大纲。
- 摘要。
- 知识卡片。
- 引用原文。
- 手工编辑。

思维导图放入 V1。

## 13. 练习教练

工作流：

```text
错题/薄弱知识点
→ 选择或生成一道练习
→ 学生作答
→ 即时反馈
→ 错因标签
→ 一道变式题
→ 写入 PracticeCompleted
```

同一知识点连续失败时：

- 降低任务复杂度。
- 推荐回看课程内容。
- 不无限生成新题。

## 14. 教学—学习数据桥

### 14.1 教师向学生

- PublishedLessonVersion。
- 讲义、课件和资料。
- 作业、截止时间和尝试规则。
- 已发布反馈。

### 14.2 学生向教师

- 查看/完成事件。
- 题目作答。
- SubmissionVersion。
- 反馈查看和采纳。
- 修订前后差异。
- PracticeCompleted。

### 14.3 学情视图

MVP：

- 完成率。
- 逾期。
- 题目正确率。
- 知识点表现。
- 常见错因。
- rubric 维度。
- 修订变化。
- 反馈查看/采纳。

不显示没有数据依据的精确“掌握概率”。

## 15. 通知

站内通知：

- 加入课程。
- 新课时。
- 新作业。
- 即将截止。
- 反馈已发布。
- 教师要求修订。

通知保存已读状态。邮件、短信和移动推送后置。

## 16. 空状态和失败状态

- 没有资料：引导上传或搜索。
- SearchProvider 失败：显示课程资料模式。
- fetch 失败：显示 URL 和 snippet-only，不冒充全文。
- RAG 处理中：允许继续编辑但不进入检索。
- Agent 部分失败：显示已有产物和重试入口。
- PPTX/DOCX 失败：结构化内容和 HTML 仍可使用。
- 发布检查失败：定位具体字段/内容，不显示模糊“发布失败”。
