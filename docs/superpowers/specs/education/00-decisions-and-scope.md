# Education 范围与决策

## 1. MVP 目标

MVP 不是功能菜单集合，而是一个可以重复执行、可以真实授权、可以失败降级的教学闭环。

成功标准：

1. 教师和学生使用不同账号。
2. 教师可以建立课程、邀请学生、备课、编辑和发布。
3. 学生只能看到已发布内容，只能提交和查看自己的数据。
4. 多 Agent 运行过程可见，每个产物可追溯到输入版本和贡献 Agent。
5. HTML、PPTX、DOCX 等产物可实际打开和继续使用。
6. 客观题可自动判分；写作反馈可由教师审核、修改和发布。
7. 学生行为和作答数据可以形成透明的学情报告。
8. 搜索或外部工具不可用时，课程 RAG 和人工编辑仍可继续工作。

## 2. 学科范围

### 2.1 高中英语旗舰

覆盖：

- 阅读材料难度和语篇类型分析。
- 词汇、语法和阅读策略。
- 阅读理解题。
- 实用文、记叙文、说明文和议论文等写作。
- Harper 写作提示。
- textstat 可读性指标。
- grammar、vocabulary、structure、content 等 rubric 维度。

### 2.2 小学语文完整轻量包

覆盖：

- 按低、中、高年级调整教案。
- 主题、课文类型和课型识别。
- 生字、拼音、多音字候选。
- 段落理解、信息提取、朗读和表达活动。
- 阅读理解、仿写、看图写话或作文。
- 基础错别字候选试验。
- 内容、结构、语言、字词和修改等适龄 rubric。

暂不覆盖：

- 高成本中文句法模型作为强依赖。
- 未经教师样本校准的“小学作文综合能力分”。
- 自动替换学生原文。

## 3. 角色范围

### 3.1 业务角色

MVP 只有：

- `teacher`
- `student`

系统管理员属于核心平台角色，不进入课程成员模型。助教、家长、教务、观察员放到后续。

### 3.2 Agent 角色

教师侧：

- 课程设计 Agent
- 课件制作 Agent
- 习题生成 Agent
- 学情分析 Agent

学生侧：

- 学习规划 Agent
- 笔记整理 Agent
- 练习教练 Agent

内部保障 Worker：

- 资料研究 Worker
- 教学审校 Worker

内部 Worker 可以出现在运行时间线中，但不必作为一级菜单。

## 4. 教学功能范围

### 4.1 教师端

- 课程、可选 Unit、课时和成员。
- 邀请码/邀请链接。
- 教师私有课程资料库。
- SearchProvider 候选搜索和受控网页抓取。
- 结构化教案生成、编辑、版本和 DOCX/HTML/PDF 导出。
- Tiptap 讲义。
- HTML 课件和可编辑 PPTX。
- 基础题型、阅读题组和写作任务。
- rubric、答案、解析和教师审核。
- 作业发布、截止时间、多次提交和修订。
- AI 辅助批改、教师确认。
- 完成率、正确率、知识点和写作维度报告。

### 4.2 学生端

- 加入课程。
- 查看已发布课时、讲义、HTML 课件和下载产物。
- 使用课程范围 Tutor。
- 上传个人资料到私有 RAG。
- 完成客观题、简答和写作。
- 查看规则提示、Agent 建议和教师反馈。
- 保存结构化笔记、摘要和知识卡片。
- 依据错题知识点获得练习、解释和一道变式题。
- 依据诊断、目标和截止时间生成学习计划。

## 5. 已确认产品决策

| 决策 | 选择 |
|---|---|
| 学生资料上传 | PDF、DOCX、TXT、Markdown、受控 URL |
| 课程层级 | Course → Unit（可选）→ Lesson → Activity |
| 加课方式 | 邀请码/邀请链接 |
| MVP 用户 | 一个教师、至少两个学生 |
| 教师工作台 | 教学设计、资料、讲义、课件、习题、发布 |
| 内容真源 | Tiptap JSON、slide JSON、assessment JSON |
| 课件 | HTML + 可编辑 PPTX；简单交互 |
| Agent 编排 | 系统模板 + 自建 + 主持规划；MVP guided |
| Agent 展示 | 任务、状态、来源、产物、交接；不展示原始思维链 |
| 审批 | 发布、反馈和最终成绩必须人工确认 |
| 题型 | 单选、多选、判断、填空、简答、阅读题组、写作 |
| 评分 | 客观题规则判分；主观题建议分 + 教师确认 |
| 提交 | 截止时间、多版本、反馈后修订 |
| Tutor 联网 | 默认课程 RAG；教师可开启明确标注的联网拓展 |
| 学习规划 | 诊断 + 目标 + 事件驱动的规则调整 |
| 笔记 | 大纲、摘要、知识卡片、引用；思维导图后置 |
| 练习教练 | 错题知识点、即时反馈、错因、一道变式题 |
| 知识点 | 能力包受控树 + Agent 建议 + 教师修改 |
| 学情 | 透明统计；掌握度模型后置 |
| 语言工具 | Harper、textstat、pypinyin；PyCorrector 先评测 |
| 搜索 | SearchProvider adapter + fallback |
| 模型隐私 | 最小化 PII、记录 provider、可关闭学生数据访问 |
| 通知 | 站内通知和未读状态 |
| 失败 | 保留部分结果，从失败节点重试，禁止自动发布 |
| 工作流范围 | 系统、个人、课程共享 |
| 教案导出 | HTML、DOCX、PDF |
| 网页版权 | 默认发布必要摘录、改编和原链接 |
| 教材来源 | 教师上传授权材料；仓库只放自有或开放示例 |
| 执行规模 | 快速处理 + 团队协作 |

## 6. 质量底线

- Agent 不能通过 Prompt 获得超出当前用户的业务权限。
- 学生不能看到草稿、答案、rubric、其他学生提交或未发布反馈。
- 网络 snippet 不能冒充网页正文。
- 语言工具建议不能自动覆盖学生原文。
- 外部内容、模型和数据集许可证分别记录。
- 所有发布和评分动作可审计。
- 所有结构化内容都保留版本。
- 所有 Agent 输出都能回溯到输入版本和 provider。
