# Spec: 4-多模态数据流 — 多模态产物内联展示系统

版本 ：v1.0
更新时间：2026.5.24

## 1. 基本信息

- 名称：4-多模态数据流 — 多模态产物内联展示系统
- 日期：2026-05-24
- 负责人：zby

## 2. 本轮目标

在 WeAgent 聊天流中实现 Agent 产物的多模态内联展示与可交互操作。Agent 不只能输出文字，还能在消息流中直接嵌入代码 Diff 对比、网页实时预览、文件附件、部署状态卡片等富媒体内容，用户可直接在聊天流中展开预览、编辑代码、一键部署。

## 3. 范围

### 本轮明确包含：

#### P0 — 核心功能
- **Web 网页预览卡片**：在消息流中内联嵌入 iframe 预览 Agent 生成的网页，支持点击展开全屏 + 代码编辑器
- **Diff 视图卡片**：在消息流中展示代码差异对比（绿色新增/红色删除），支持一键应用 Diff
- **部署状态卡片**：Agent 执行"部署"后返回实时部署进度、预览 URL、日志
- **消息操作栏增强**：回复（引用）、重新生成（触发 Agent 重新响应）、复制代码、一键应用 Diff、展开预览
- **全屏预览 + 代码编辑器**：点击卡片展开全屏覆盖层，左侧实时预览，右侧代码编辑，编辑后可保存新版本

#### P1 — 增强功能
- **文档预览卡片**：Markdown 文档内联渲染
- **PPT 预览卡片**：幻灯片浏览模式（上一页/下一页）

#### P2 — 高级功能
- **版本历史**：产物版本列表、版本间 Diff 对比、回滚
- **对话式局部修改**：在代码预览中选中代码片段 → 在聊天中描述修改
- **部署发布流程**：聊天中发送"部署" → Agent 返回部署选项 → 静态站点/容器化部署/源码打包下载

### 本轮明确不包含：

- 接入真实 AI 模型（仍使用模拟 Agent 响应）
- 真实的容器化部署环境（使用 Mock Provider 模拟流程）
- 多 Agent 群聊场景下的产物冲突合并
- 产物权限管理

## 6. 验收标准

- [ ] Agent 回复中的网页产物能以卡片形式内联在消息流中，点击展开可进入全屏预览
- [ ] Agent 回复中的部署状态卡片能实时更新进度，显示预览 URL 和日志
- [ ] 每条消息 hover 显示操作栏：回复、引用、重新生成、复制代码
- [ ] 代码块可复制、可展开到全屏代码预览
- [ ] 文档/PPT 产物可在消息流中内联预览
- [ ] 产物版本历史可查看、可对比 Diff
- [ ] 选中代码后弹出"在聊天中描述修改"浮层
- [ ] 部署流程：输入"部署" → 选择部署方式 → 实时状态 → 获取访问 URL

## 7. 风险与限制

- **elements 子类型无 schema 约束**：当前 text/code/table/image/file 仅在代码中约定，新增类型需前后端同步
- **message_type 枚举三处同步**：SQL、Model、Schema 需手动同步，容易遗漏
- **数据库外键循环依赖**：`项目运行.md` 已记录此问题，建表不能使用 init 脚本
- **SSE 硬编码 localhost**：`Dashboard.vue:341` SSE URL 写死了 `http://localhost:5000`，部署时需改为配置
- **无真实 AI 模型**：当前使用 `_mock_agent_response()` 模拟，需确认模拟数据能否覆盖所有新卡片类型
