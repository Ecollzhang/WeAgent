## 2. 本轮背景与初始判断

Diff 视图卡片完成后，按 spec 规划接下来做 Web 网页预览卡片。初始判断是实现一个内联 iframe 卡片 + 全屏预览 + 源码编辑即可，用户逐步提出更多需求，最终演化成一个完整的可视化页面编辑器。

## 3. 讨论过程

- 【进展】实现 WebPreviewCard 内联 iframe 预览卡片 + ArtifactFullscreenPreview 全屏预览
- 【修正】多次迭代修复：预览/编辑/可视化三种模式合并、属性面板加载失败、文本内容编辑
- 【修正】可视化编辑工具栏从粗粒度改为精简（撤销/重做/布局修改/插入图片），所有样式编辑移至右侧属性面板
- 【重构】存储分层：`visualHtml`（iframe 稳定显示）与 `savedHtml`（保存/源码用）分离，解决 iframe 每次修改刷新问题
- 【进展】属性面板实现：选中元素后显示宽高/间距/颜色/字号/对齐/粗细/边框等 CSS 属性编辑
- 【进展】层级树实现：解析 HTML 生成树状结构，左侧面板显示，带展开收起/虚线连接/双向高亮/可拖拽宽度
- 【问题】层级树路径与 iframe 内路径不一致导致点击不跳转 → 修复：`stripInjected()` 剥离工具栏，`buildLayerTree` 和 `getPath` 两端使用相同的过滤逻辑
- 【问题】HTML5 拖拽双向无效 → 改为 DOM 位置遍历判断方向
- 【进展】工具栏按钮：布局修改（拖拽排序）、插入图片（base64 以 div 包裹插入）、撤销/重做（先 focus 编辑元素）
- 【进展】属性栏底部新增复制/删除组件按钮（cloneNode + remove）
- 【验证】前后端编译通过，迭代式修复约 10 轮

## 4. 当前收敛结果

- `WebPreviewCard/index.vue` — 消息流内联网页预览卡片
- `ArtifactFullscreenPreview/index.vue` — 全屏可视化编辑器，含：
  - 可视化编辑 / 源码编辑双模式
  - 顶部工具栏（撤销/重做/布局修改/插入图片）
  - 右侧属性面板（尺寸/间距/外观/边框 + 文本内容编辑）
  - 左侧层级树（可拖拽调宽/展开收起/虚线连接/双向高亮）
  - 底部组件管理（复制/删除）
  - 布局修改模式（拖拽排序，前后双向有效）

## 5. 未解决问题 / 后续建议

- 撤销/重做依赖 `document.execCommand`，仅对 contentEditable 文本编辑有效，对属性面板的样式修改不生效
- 层级树路径匹配可能因 HTML 结构差异仍有边界情况
- 插入的图片以 base64 存储，体积较大，后续可考虑上传至服务器
- 拖拽排序在复杂嵌套结构下可能不稳定
