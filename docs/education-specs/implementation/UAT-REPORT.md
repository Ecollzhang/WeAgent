## 1. 验收结论

截至 2026-07-29，Education 已形成可演示的真实多用户闭环，并完成教师端、学生端双重
验证：

- 教师端以三个独立业务领域组织：**教学空间**、**PPT 与课件**、**学生画像与评估**。
- 学生端历史基线曾以 **模拟考试**、**作业弱点**、**课程思维导图** 组织；新合同改为
  **教学空间**、**模拟考试**、**课程思维导图**，作业弱点进入教学空间。
- 课程、成员、课时、教案、课件版本、正式成绩与 Agent 写入产物均保存在 Education
  数据库；临时 sandbox 和聊天不是业务真源。
- Agent 通过受控 Education Tool Gateway 读取课程上下文并写入正式对象；没有完成要求的
  持久写工具调用时，产品运行不会被标记为完成。
- 图文帮助中心覆盖教师和学生两条真实路径，并提供对应领域的直达入口。

## 3. 教师端浏览器 UAT

标杆课程为“高中英语 · 叙事阅读与写作 UAT”，课时为“A Turning Point · 叙事阅读与
续写”。浏览器复核结果：

1. 左侧仅显示教学空间、PPT 与课件、学生画像与评估三个教师领域。
2. PPT 与课件页能够选择真实课程和课时，并读取 3 个教学目标及课时上下文校验码。
3. 真实 Agent 运行中，课程设计师与课件制作 Agent 均调用课程上下文读取工具，课件制作
   Agent 调用 `edu.courseware.create` 写入正式 `SlideDocument`；工具读写记录可在折叠区
   查看，但 Conversation ID、Sandbox ID 和原始推理不在产品页面显示。
4. Agent 生成的 6 页结构化课件保存为 v1；教师在结构化幻灯片编辑器中修改标题并保存为
   同一内容的 v2，版本时间和说明正确显示。
5. 当前版本支持 PPTX、DOCX、PDF、HTML、JSON 导出；标题、简单文本/列表和讲者备注可
   编辑，复杂结构在 MVP 中保真展示并随版本保存。
6. 学生画像显示正式成绩最高分 90、最低分 70、平均分 80、中位数 80、完成率 100%，并
   渲染成绩分布与趋势图；两名学生分别可下钻到来源证据。
7. 图文帮助中心的教师步骤可直达建课、课件和画像领域。

## 4. 学生端浏览器 UAT

使用课程中的真实学生账号重新登录后复核：

1. 当前课程身份由服务端成员关系显示为“学生”，没有可绕过权限的角色开关。
2. 历史基线左侧显示模拟考试、作业弱点、课程思维导图；此项已被新导航合同取代，需重新
   验收教学空间、模拟考试、课程思维导图。
3. 三个领域均可正常进入；数据不足时给出明确空状态，不伪造弱点或考试结果。
4. 直接访问教师课件 URL 时，不出现上传、AI 生成、编辑或导出操作，只显示“当前没有可用
   的教师课程”。
5. 学生帮助页覆盖加入课程、模拟考试、作业弱点和课程思维导图，并再次说明只可查看已发布
   内容、本人提交和反馈。
6. 服务端自动化权限矩阵继续验证学生不能读取教师草稿、答案、rubric、其他学生数据或教师
   课程上下文接口。

## 5. Agent 与持久工具 UAT

- Product Agent 提示词明确区分两套输出：聊天可见说明与严格结构化工具参数；禁止把
  JavaScript 文件当作课程产物或依赖无限兼容解析。
- Native MCP 工具以 server/tool alias 注入，Agent 不需要伪造 MCP resource 读取。
- 课程、课时和当前教案/目标/活动/材料由服务端构建稳定上下文投影并附校验码。
- 工具调用具备课程、课时、角色、TTL、幂等与审计边界。
- moderator 已生成计划但 worker 消息尚未可见时，运行保持进行中，避免竞态误判失败。
- 历史上缺少要求写工具调用却被乐观标记完成的运行，会在读取时校正为 `partial`。
- 一次性 Agent UAT sandbox 在验收后删除，数据库中的课件 v1/v2 仍可查看和导出。

## 6. 正式成绩口径

- 作业保留 `score` 与 `max_score`，跨不同满分任务先换算为百分制。
- 只统计规则判分完成的客观题和教师确认后的主观题最终分。
- AI 建议分不进入最高、最低、平均、中位数或成绩分布。
- 班级总览与单个学生画像使用同一后端证据投影，前端图表不自行重算业务口径。

## 9. 新合同待验收矩阵

以下内容尚未在本报告中通过，实施完成后必须追加新的可复现证据：

- 任一 Education 页面只有一根全局主侧栏和一个教学空间入口；课程切换位于页面顶部。
- 学生在教学空间下载课件/材料、完成作业、查看反馈和作业弱点。
- 业务页只显示最新运行/产物，可进入本次聊天和协作历史；聊天可返回业务页面。
- 实际工具目录缺少 `edu.courseware.create` 时 preflight 失败且不启动完整团队。
- schema 修复与 writer 定向重试；成功时留下可读取版本，失败时留下可恢复草稿。
- 删除 sandbox 后旧聊天、Workflow、正式产物和已快照预览仍可打开；继续聊天创建新
  runtime generation。
- 多风格阶段至少四种风格通过逐页截图视觉检查和 PowerPoint/LibreOffice 打开验证。
