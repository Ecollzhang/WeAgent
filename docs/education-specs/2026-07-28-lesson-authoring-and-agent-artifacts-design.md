# Education 课时创作与 Agent 产物预览设计

## 目标

修复教案字段因 Vue runtime-only 构建而不渲染的问题，并将课时工作台升级为教师可直接使用的创作界面。教师无需编写 HTML；Agent 的每份产物都可见、可预览、可采用，同时保持教案私有和学生发布快照隔离。

## 已确认交互

### 教案

- 教学目标、教学活动、评价与作业使用预编译 Vue 单文件组件。
- 每个字段支持常规编辑和放大编辑。
- 课程设计 Agent 的对象数组输出先归一化为可读文本，再写入编辑器。

### 课件

- 使用 wangEditor Vue 2 组件，不继续扩展已废弃的 `document.execCommand` 编辑器。
- 工具栏覆盖标题、字体、字号、加粗、斜体、下划线、删除线、颜色、对齐、缩进、列表、引用、链接、撤销/重做和清除格式。
- HTML 是结构化存储及 Agent 产出格式；教师操作的是所见即所得界面。
- 学生端仍通过受限 iframe 安全预览发布快照。

### Agent 产物

- 前端不显示 Conversation ID 和 Sandbox ID。
- 每个 Agent 节点展示状态、产物摘要以及“预览产物”入口。
- 课程设计师、习题生成器、教学审校员分别使用专用渲染器；不能结构化的结果显示可读文本和校验状态。
- 原始 JSON 只放在可选的“查看原始数据”折叠区，不作为主界面。
- 采用课程设计师产物只改变当前草稿，不自动保存或发布。

### 保存和发布

- `Ctrl/Cmd+S` 保存新版本。
- `Ctrl/Cmd+Enter` 触发发布。
- 编辑器维护基线快照；教案或课件变化后显示“有未保存更改”。
- 发布时若存在未保存更改，明确提示并提供“先保存再发布”。
- 离开课时页面时，如果仍有未保存修改，触发离开确认。
- 发布始终引用服务器中已保存的不可变版本。

## 模块边界

- `LessonPlanEditor`：组合教案字段，不包含动态运行时模板。
- `EditableLessonSection`：单个可放大的文本字段。
- `RichMaterialEditor`：wangEditor 适配层，只暴露 HTML `v-model` 和编辑事件。
- `AgentArtifactPreview`：按 `agent_role` 选择渲染器。
- `educationContent`：Agent 数据归一化、版本时间和脏状态快照工具。
- `LessonWorkbench`：页面编排、保存发布状态机和快捷键。

后续自定义 Agent 组合沿用后端 `WorkflowTemplate`，前端增加编排器时只需提供节点选择、依赖连线和产物渲染器注册，不修改课时保存发布契约。

## 验收接口

- 浏览器中教案四类字段全部可见，采用 Agent 后立即出现内容。
- 课件工具栏可执行常用排版，保存并刷新后格式仍存在。
- Agent 区不出现运行 ID，每个已完成 Agent 都能打开产物预览。
- 脏状态、快捷键和发布前自动保存提示可观察。
- 教师发布后学生能查看课件和材料，但不能查看教师教案或审校私有信息。
