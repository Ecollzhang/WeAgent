三个课时分别围绕：

1. 情节证据与牺牲选择。
2. “wise / foolish”反讽判断与 CER 分析段落。
3. Jim 进门时刻的叙事视角改写。

三个作业分别要求文本定位、证据解释和视角写作，形成阅读理解—分析写作—叙事迁移的连续证据链。

## 3. 浏览器 UAT 记录

### 3.1 教师视角

- 首次进入真实课程后，左侧为“教学空间 / PPT 与课件 / 学生画像与评估 / 帮助中心”，不再出现第二列重复教育导航。
- 教学空间展示 3 个已发布课时和严格 2×2 的教师操作区。
- 知识中心把真实文章显示为一个材料题组，正文可展开，7 道子题按顺序呈现；六种题型都显示正确类型。
- 试卷“学生视图”只显示材料、题干、分值和规范的 `A/B/C/D` 选项，不泄露答案；教师可切含答案视图。
- 成绩总览切换两份不同作业后，最高/最低/平均/中位数、提交率和分布同步变化；课程平均分趋势不混入模拟考试。
- 学生画像首屏只显示 3 人，存在“加载更多（剩余 4 人）”；打开陈雨桐画像后可回溯 3 条具体作业证据。
- 作业总览显示姓名而非用户 UUID；打开单份提交后，AI 建议默认收起，只保留一个教师反馈。
- 旧批改记录只保存总分时，工作台回显 `68 / 100`，不会误显示 0；恢复的分项有显式确认提示。

### 3.2 学生视角

- 使用此前从未进入 Education 的第二名学生复验：首次选择“智慧教育”后即显示“教学空间 / 模拟考试 / 课程思维导图 / 帮助中心”，无需先进入某门课触发角色识别。
- 教学空间只显示“课件与材料 / 完成作业 / 作业弱点”，不显示教师操作。
- 陈雨桐的作业弱点显示 3 条来自已发布教师反馈的证据；未读取聊天内容推测能力。
- 思维导图查看态没有右侧空白检查器；进入编辑后才显示节点编辑区，提供双击编辑、受控颜色、撤销/重做、居中和导出。
- 学生帮助中心默认打开“学生快速开始”，不再先展示教师流程。
- 学生 API 和试卷预览均不包含教师答案、解析或未发布草稿。

## 4. 英语教师产品审阅

### 4.1 适合课堂使用的部分

- 题库不再把阅读理解拆成互不相关的单选题：文章只呈现一次，下面连续组织事实定位、推断、多选、判断、填空、简答和写作迁移。
- 问题顺序符合教学推进：先确认文本事实，再解释证据，最后迁移到分析和创作。
- 试卷使用冻结版本，教师后续修改题库不会污染已经开始的考试或已发布材料。
- 学生弱点来自教师正式反馈和得分证据；高分学生不会因正向评价被错误标记为薄弱。
- 班级总览能切换具体作业，适合教师区分“文本理解弱”还是“写作迁移弱”，比混合全课程得分更可行动。

### 4.2 教师使用边界

- Project Gutenberg 节选适合公开演示；真实校内使用时，教师仍需确认教材版本、地区版权和本校课程要求。
- 课堂节选不替代全文阅读，系统保留全文来源链接和改写说明。
- AI 批改只作为可折叠建议，正式分数和对学生反馈仍由教师确认发布。
- 学生画像是证据索引，不是性格分类或无依据的能力概率。

## 6. 可重复 UAT

脚本：`backend/scripts/uat_phase4_authentic_english.py`

运行要求：

1. Core API、Education API 和前端已启动。
2. 在当前进程设置 `WEAGENT_UAT_PASSWORD`，不要把密码写进命令历史或仓库。
3. 脚本会优先复用同名课程并校验数量、发布状态、学生答案隔离和弱点证据，不会依赖 Docker 沙箱保存最终业务数据。

业务真源仍是 Education 数据库；关闭 Agent Docker 会影响正在运行的会话计算，但不会删除本报告中的课程、题目、试卷、作业、反馈、画像或思维导图。
