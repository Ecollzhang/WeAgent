# Education 教师端与学生端体验

## 1. 体验原则

- 功能围绕课程和课时，不围绕聊天窗口组织。
- Agent 协作可见，但不要求用户理解底层 provider。
- 所有 AI 内容可编辑。
- 教师始终知道哪些内容尚未发布。
- 学生始终知道内容来源和反馈状态。
- 失败、fallback 和旧版本状态不能被隐藏。

## 2. 教师端独立领域

Education 在全局 WeAgent 导航内增加角色感知的领域栏。教师一级领域固定为：

- 教学空间
- PPT 与课件
- 学生画像与评估

角色按当前课程成员关系确定，不提供绕过课程权限的全局角色切换。
三个入口是各自拥有页面流程和数据模型的业务领域，不是 Agent 协作台的三个标签。
Agent 是领域内部的生成、分析和校验能力；不要求教师先创建聊天或进入通用协作界面。

课程内二级导航：

- 概览
- 单元与课时
- 成员
- 课程资料库
- 作业
- 学情
- 工作流模板
- 设置

### 2.1 PPT 与课件领域

主流程固定为：

```text
选择教师课程
  → 选择课时
  → 聚合该课时的教案、目标、活动、材料和授权知识来源
  → 生成或编辑 SlideDocument
  → HTML 预览
  → 保存不可变版本
  → 导出 PPTX / PDF / HTML
```

- `slide JSON` 是可编辑真源；HTML、PPTX 和 PDF 是渲染或导出格式。
- 教师可以上传已有 PPTX、PDF、DOCX 或 HTML 作为课程资产。
- “AI 生成”“局部重写”“页面检查”是普通领域动作，不跳转到协作台。
- Agent 过程默认折叠为“AI 生成记录”，显示产物、来源、状态、fallback 和工具结果。
- Conversation ID、Sandbox ID、系统 Prompt、provider 细节和原始思维链不显示。

### 2.2 学生画像与评估领域

进入课程后先显示班级总览，再下钻到学生：

- 最高分、最低分、平均分、中位数、已评分人数、作业完成率、成绩分布和趋势。
- 单个作业/考试同时显示原始分和满分；跨作业/考试的课程总览先换算百分制再聚合，
  避免不同满分直接求平均。
- 可按作业/模拟考试、时间范围、阅读/写作和知识点筛选。
- 学生卡片显示最终成绩趋势、完成情况、知识点证据、常见错因和 rubric 维度。
- 每个画像结论都能展开到具体作业提交、考试作答或教师评分。
- 客观题规则判分和教师确认后的主观题 `final_score` 进入正式统计。
- AI 主观题建议分单独标记“待教师确认”，不进入最高分、最低分、平均分或排名。
- 无足够证据时显示“数据不足”，不生成性格标签或虚构掌握度。

### 2.3 领域视觉与动效

- 延续绿色、纸张和教学材料的视觉语义，避免套用通用数据大屏。
- 首次进入使用一次克制的分段出现；数值、图表和版本切换使用短时过渡。
- hover、focus、loading 和成功落库必须有明确反馈，但不以动画替代状态文字。
- 支持 `prefers-reduced-motion`，移动端减少装饰层和位移。

## 3. 创建课程

教师步骤：

1. 输入课程名称。
2. 选择学科和年级。
3. 绑定 SubjectPackVersion。
4. 选择或跳过 Unit 结构。
5. 获取邀请码/邀请链接。
6. 上传初始课程资料。

创建后默认：

- course status 为 draft。
- teacher membership active。
- 学生不能看到任何未发布内容。

## 4. 课时工作台

统一工作台标签：

```text
教学设计 | 资料 | 讲义 | 课件 | 习题 | 发布
```

### 4.1 教学设计

- 上传或选择课文。
- 输入课时、班级和教师目标。
- 查看 Agent 推荐的主题、文本类型和课型。
- 教师确认分类。
- 选择系统/个人/课程工作流。
- 生成和编辑结构化教案。
- 查看目标—活动—评价校验。
- 导出 DOCX/HTML/PDF。

### 4.2 资料

- 课程 RAG 资料。
- SearchProvider 搜索候选。
- 显示 title、URL、snippet、provider。
- 教师选择后再 fetch 正文。
- 显示 full/partial/snippet-only 状态。
- 选择引用或排除来源。

### 4.3 讲义

- Tiptap 编辑。
- 引用、词汇/生字、提示、问题等教育节点。
- Agent 局部重写。
- 版本比较。

### 4.4 课件

- SlideDocument 页面列表。
- HTML 预览。
- 页面级编辑和局部重新生成。
- PPTX 导出。
- 显示课件基于的教案版本。

### 4.5 习题

- 题型和知识点过滤。
- 题目编辑。
- 答案/解析教师私有视图。
- rubric。
- 预估难度明确标记来源。

### 4.6 发布

发布检查清单：

- 当前教案版本。
- 讲义/课件版本。
- 作业和题目。
- 学生可见范围。
- 答案泄漏检测。
- 外部引用状态。
- Artifact 可用性。

教师确认后生成不可变版本。

## 5. 领域内 Agent 能力与运行记录

该区域默认折叠，不作为领域首页主结构。页面先展示已经落库的课件版本、成绩统计或
画像证据；教师需要复核生成过程时再展开“AI 生成记录”或“分析依据”。

显示任务图或时间线：

- 节点名称。
- Agent。
- pending/running/done/failed/skipped/approval。
- 输入版本。
- 产物。
- fallback。
- 重试。
- 教师审批。

示例：

```text
课程设计 Agent       教案 v3 已完成
资料研究 Worker       4 个来源，1 个 snippet-only
课件制作 Agent       HTML 已完成，PPTX 生成中
习题生成 Agent       8 道题等待审校
教学审校 Worker       发现 2 道题答案依据不足
教师确认              等待处理
```

不展示原始思维链、系统 Prompt 和 secret。

## 6. 自建工作流

复用现有工作流图体验，增加：

- 系统/个人/课程模板库。
- Agent/动作节点选择器。
- required approval gate。
- DAG 校验。
- capability/权限提示。
- 版本和复制。
- 服务端保存。

保存前检查：

- 节点 ID 唯一。
- 不存在循环。
- 所有 Agent 在教育 workspace 可用。
- 所有 capability 已配置。
- required gate 未被删除。
- 并发数和节点数不超限。

## 7. 学生端导航

学生一级模块固定为：

- 模拟考试
- 作业弱点
- 课程思维导图

课程学习内容、作业、反馈和资料作为当前课程上下文进入上述模块，不再复制成一组
互相竞争的一级菜单。

## 8. 学生课时页

显示：

- 课时目标。
- 讲义。
- HTML 课件。
- 资料和引用。
- 阅读活动。
- 随堂练习。
- 写作任务。
- Tutor。

来源标识：

- 课程资料。
- 教师内容。
- 网络拓展。
- AI 生成。
- 模型推断。

## 9. Tutor

默认：

- 只访问 `course_published` + 本人 `student_private`。
- 不直接给出进行中作业答案。
- 优先提示、提问、定位课程资料。
- 引用可点击回源。

教师开启联网拓展后：

- 明确显示“联网拓展”。
- 遵循 Search → Fetch → Retrieve。
- 不允许学生直接选择任意危险 URL 抓取。

## 10. 作业与写作

### 10.1 客观题

- 即时保存。
- 符合教师策略时即时反馈。
- 提交后规则判分。

### 10.2 写作

- Tiptap/结构化文本编辑。
- 自动保存。
- Harper 或语文规则候选。
- 建议逐条接受/拒绝。
- 提交生成不可变 SubmissionVersion。
- 教师反馈后允许一次或教师配置次数的修订。
- 显示版本差异。

## 11. 学习规划

输入：

- 诊断题。
- 当前知识点表现。
- 作业截止时间。
- 教师目标。
- 学生可用时间。

输出：

- 每日/每周任务。
- 预计时长。
- 关联课程内容。
- 完成状态。
- 调整原因。

MVP 使用透明规则调整，不宣称长期最优路径。

## 12. 笔记整理

支持：

- 粘贴/上传零散笔记。
- 选择课程资料。
- 结构化大纲。
- 摘要。
- 知识卡片。
- 引用原文。
- 手工编辑。

思维导图放入 V1。

## 13. 练习教练

工作流：

```text
错题/薄弱知识点
→ 选择或生成一道练习
→ 学生作答
→ 即时反馈
→ 错因标签
→ 一道变式题
→ 写入 PracticeCompleted
```

同一知识点连续失败时：

- 降低任务复杂度。
- 推荐回看课程内容。
- 不无限生成新题。

## 14. 教学—学习数据桥

### 14.1 教师向学生

- PublishedLessonVersion。
- 讲义、课件和资料。
- 作业、截止时间和尝试规则。
- 已发布反馈。

### 14.2 学生向教师

- 查看/完成事件。
- 题目作答。
- SubmissionVersion。
- 反馈查看和采纳。
- 修订前后差异。
- PracticeCompleted。

### 14.3 学情视图

MVP：

- 完成率。
- 逾期。
- 题目正确率。
- 知识点表现。
- 常见错因。
- rubric 维度。
- 修订变化。
- 反馈查看/采纳。

不显示没有数据依据的精确“掌握概率”。

## 15. 通知

站内通知：

- 加入课程。
- 新课时。
- 新作业。
- 即将截止。
- 反馈已发布。
- 教师要求修订。

通知保存已读状态。邮件、短信和移动推送后置。

## 16. 空状态和失败状态

- 没有资料：引导上传或搜索。
- SearchProvider 失败：显示课程资料模式。
- fetch 失败：显示 URL 和 snippet-only，不冒充全文。
- RAG 处理中：允许继续编辑但不进入检索。
- Agent 部分失败：显示已有产物和重试入口。
- PPTX/DOCX 失败：结构化内容和 HTML 仍可使用。
- 发布检查失败：定位具体字段/内容，不显示模糊“发布失败”。

## 17. 教师端与学生端双重验收

教师端必须验证：

- 能从课程和课时进入课件领域，生成、编辑、保存多版本并导出。
- 班级最高/最低/平均/中位数、完成率和分布只使用正式成绩。
- 每个画像结论可下钻到具体提交、考试作答或教师评分。
- Agent 写操作经过 Tool Gateway，产物在删除临时 sandbox 后仍可使用。

学生端必须验证：

- 只能看到当前课程已经发布的课件、材料、题目和反馈。
- 看不到教师草稿、私有答案、rubric、AI 待确认分、其他学生数据和分析依据。
- 模拟考试、弱点分析和思维导图写入自己的持久数据，刷新页面后仍存在。

## 18. 图文帮助中心

MVP 在领域流程稳定后提供轻量帮助中心，不引入重型 CMS：

- 教师快速开始：创建课程、建立课时、制作并导出课件、查看班级画像。
- 学生快速开始：加入课程、完成任务、查看弱点、生成思维导图。
- 每个步骤使用真实界面截图或仓库维护的轻量示意图，配短说明和直达按钮；示意图不得引入
  与业务无关的重型图片依赖。
- 帮助内容与当前路由、按钮名称和角色权限保持一致，并纳入 UAT 检查。
- 教师和学生两个标签都必须通过浏览器 UAT；帮助中心本身不能泄露另一角色的私有操作或数据。
