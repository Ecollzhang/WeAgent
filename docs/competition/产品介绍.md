# WeAgent Domain — 领域化多智能体协作平台

> **一句话定位**：为不同专业领域提供专属AI Agent团队的协作工作台，让每个人拥有自己的"AI团队"。

---

## 一、产品概述

WeAgent Domain 是一款**领域化多智能体协作平台**。它不再是"一个AI聊天机器人"，而是将多个专业AI Agent组成团队，按领域（研发、教育、办公）封装为独立的工作空间——每个空间拥有专属的Agent角色、知识库、工具集和协作流程。用户像管理一个小型团队一样与AI协作，完成从任务规划、分工执行到产物交付的全流程。

**核心差异**：不是让一个通用AI做所有事，而是让合适的AI Agent团队处理合适领域的专业任务。

## 二、三大领域空间

### 2.1 智能研发（Smart R&D）

**定位**：面向开发者、数据工程师、技术团队的AI研发协作空间。

**Agent团队**：

| Agent角色 | 职责 |
|---|---|
| **架构师Agent** | 技术方案设计、系统架构评审、技术选型建议 |
| **开发Agent** | 全栈代码编写（Python/前端/后端）、功能实现、API开发 |
| **测试Agent** | 测试用例生成、自动化测试脚本、Bug分析报告 |
| **数据分析Agent** | 数据清洗、统计分析、可视化报表、业务洞察 |
| **文档Agent** | 技术文档撰写、API文档生成、README编写 |

**核心场景**：

- **全栈项目开发**：需求分析→架构设计→前后端编码→测试→文档，全流程Agent协作
- **数据分析报告**：上传数据→Agent自动清洗分析→生成可视化报表与解读
- **代码审查**：提交代码→审查Agent自动审查→输出问题清单与修改建议
- **技术调研**：指定主题→多Agent分工检索与汇总→生成技术调研报告

**亮点**：这是我们平台**已有核心能力的直接映射**——现有的编程、测试、设计、数据分析Agent类别天然构成研发空间，无需从零构建。

---

### 2.2 智慧教育（Smart Education）

**定位**：面向教师和学生，覆盖"教"与"学"全流程的AI教育协作空间。

**Agent团队（教师侧）**：

| Agent角色 | 职责 |
|---|---|
| **课程设计Agent** | 教学目标设计、教学活动规划、教案编写 |
| **课件制作Agent** | 交互式课件生成（PPT/HTML）、教学动画、知识图谱可视化 |
| **习题生成Agent** | 根据知识点自动生成练习题、自动组卷、难度校准 |
| **学情分析Agent** | 学生成绩分析、知识点掌握度诊断、教学建议输出 |

**Agent团队（学生侧）**：

| Agent角色 | 职责 |
|---|---|
| **学习规划Agent** | 知识诊断、学习路径推荐、学习计划制定 |
| **笔记整理Agent** | 零散笔记结构化、思维导图生成、知识卡片制作 |
| **练习教练Agent** | 自适应练习推送、实时反馈、错因诊断、举一反三 |
| **项目导师Agent** | 编程项目指导、实验设计建议、论文写作反馈 |

**核心场景**：

- **教师备课全流程**：课程设计→课件制作→习题生成→课后学情分析，一站式完成
- **个性化学习**：学生上传学习材料→Agent诊断薄弱点→生成专属学习路径→伴随式练习
- **教-学闭环**：教师发布作业 → 学生接收完成 → 自动批改 → 学情反馈给教师

**亮点**：教师和学生使用同一平台的不同空间，通过"教学-学习数据桥"形成闭环——教师的课件和作业可一键发布给学生，学生的练习数据自动回流为学情报告。这种"教"与"学"一体化的Agent协作生态，在同类产品中独树一帜。

### 2.3 智慧办公（Smart Office）

**定位**：面向行政人员、管理人员、中小企业的AI办公协作空间。

**Agent团队**：

| Agent角色 | 职责 |
|---|---|
| **公文撰写Agent** | 通知、报告、请示、函等各类公文起草，符合格式规范 |
| **会议助理Agent** | 会议议程生成、录音纪要整理、决议与行动项提取 |
| **报表分析Agent** | Excel/CSV数据分析、统计报表生成、趋势图表输出 |
| **邮件起草Agent** | 商务邮件撰写、通知发布、汇报邮件、语气调整 |
| **日程管理Agent** | 日程规划、优先级排序、会议时间协调 |

**核心场景**：

- **会议全流程**：会前生成议程→会后录音转纪要→提取决议与行动项→邮件分发
- **公文处理链**：起草→格式审核→修订→定稿输出，多Agent流水线协作
- **数据汇报**：上传原始数据→Agent分析→生成可视化报表→输出汇报PPT大纲

**亮点**：模拟真实办公团队的协作模式——文秘起草、主任审核、数据分析员出报表、助理发邮件。Agent之间有明确角色边界和协作流程，不是"一个AI写一切"。

## 三、平台核心能力

### 3.1 领域隔离架构

```
┌────────────────────────────────────────────┐
│               WeAgent Domain                │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  │
│  │ 智能研发  │  │ 智慧教育  │  │ 智慧办公  │  │
│  │          │  │          │  │          │  │
│  │ 专属Agent│  │ 专属Agent│  │ 专属Agent│  │
│  │ 专属知识库│  │ 专属知识库│  │ 专属知识库│  │
│  │ 专属工具集│  │ 专属工具集│  │ 专属工具集│  │
│  │ 专属工作流│  │ 专属工作流│  │ 专属工作流│  │
│  └──────────┘  └──────────┘  └──────────┘  │
│                                             │
│      共用底层：Agent调度引擎 + Docker沙箱     │
│                + 多模型适配 + 实时事件       │
└────────────────────────────────────────────┘
```

每个领域空间完全隔离——研发Agent不懂公文格式，教育Agent不会写代码（除非是教学需要），办公Agent不碰数据库。领域切换即切换整套Agent团队和协作环境。

### 3.2 多Agent协作调度（已有核心能力）

- **主持Agent任务分解**：接收用户自然语言指令→分析任务→生成JSON调度计划（任务拆分、Agent分配、并行/串行编排）
- **Worker Agent并行执行**：多个Agent在独立Docker沙箱中并行工作，互不干扰
- **结果汇总与审核**：主持Agent收集Worker输出→审核质量→汇总交付

### 3.3 Docker沙箱隔离执行（已有核心能力）

每个会话创建独立Docker容器，Agent在容器内执行——文件系统隔离、网络隔离、工具环境隔离。确保Agent执行安全可控，且"写完即运行"可在沙箱内直接验证代码和生成预览。

### 3.4 多引擎模型适配（已有核心能力）

统一接入Claude Code、OpenAI Codex、OpenCode三种AI引擎，可按Agent角色选择最适合的底层模型，不被单一厂商锁定。

### 3.5 多类型产物交付（已有核心能力）

Agent产出不限于文本，包括：
- 代码文件（支持在线编辑与运行）
- HTML网页（沙箱内实时预览）
- 数据表格与图表
- Markdown文档
- PPT大纲/课件
- Diff对比视图

### 3.6 全平台覆盖（已有核心能力）

Web端 + Electron桌面端 + Android移动端，一套后端协议三端共享。

## 四、核心创新点

### 创新一：领域隔离的Agent工作空间

**现状问题**：通用AI助手在不同任务间共享上下文，角色混淆，专业性不足。

**我们的方案**：每个领域拥有完全独立的Agent团队、知识库、工具集和工作流模板。切换领域 = 切换一整套专业协作环境。类比微服务架构对单体应用的改造——不是让一个Agent变全能，而是让合适的Agent团队处理合适的领域任务。

### 创新二：可插拔的领域能力包

每个领域的完整能力（Agent角色定义、System Prompt、工具、知识库、工作流模板）被打包为独立的能力包，支持一键安装和切换。未来可扩展至智慧医疗、智慧城市、数字文旅等任意新领域，无需改动平台核心。

### 创新三：教育"教-学"双循环生态

智慧教育空间内，教师端和学生端通过数据桥形成闭环：教师设计课程→发布作业→学生完成→自动批改→学情报告反馈给教师→教师调整教学策略。教与学在同一平台上形成持续优化的反馈循环，这是其他Agent产品不具备的独特生态。

### 创新四：从"AI工具"到"AI团队"的协作范式升级

用户与Agent的交互不再是"提问-回答"，而是像管理一个微型团队：
- 下达任务 → 主持Agent自动分工 → Worker并行执行 → 主持审核汇总 → 交付成果
- Agent之间有明确的角色边界（文档Agent不写代码，开发Agent不写公文）
- 协作过程实时可见（进度条、工作流图、产物逐步生成）

### 创新五：以真实项目基础构建，非Demo级原型

本产品基于已完整实现的多Agent协作引擎构建，核心技术（调度、沙箱、多引擎、实时事件）均已经过工程验证。参赛作品不是"能跑通的Demo"，而是"可以实际使用的产品"。

## 五、典型使用场景

### 场景一：开发者的一天（智能研发）

> 小张是创业团队的全栈工程师。他打开WeAgent切换到"智能研发"空间，输入："帮我做一个用户反馈收集页面，后端用Flask，前端用Vue，要有表单提交和管理后台查看功能。"
>
> 主持Agent（架构师）分析需求→拆分为：数据库设计、后端API、前端页面、测试用例4个子任务→分配给开发Agent、前端Agent、测试Agent并行执行。15分钟后，小张获得了完整的项目代码、数据库Schema、API文档和测试脚本，所有产物可在沙箱内直接预览运行。

### 场景二：教师备课（智慧教育）

> 王老师打开WeAgent切换到"智慧教育"空间，输入："我要准备一堂初中物理'浮力'公开课，45分钟，学生基础一般，需要互动实验。"
>
> 课程设计Agent输出教学设计方案→课件制作Agent生成包含阿基米德实验交互模拟的HTML课件→习题生成Agent输出课堂练习和课后作业。王老师在沙箱中预览课件效果，满意后一键发布到学生端。课后，学情分析Agent自动汇总学生练习数据，生成班级掌握度报告。

### 场景三：行政办公（智慧办公）

> 李主任刚开完项目启动会。他上传会议录音转写文本到"智慧办公"空间，输入："整理会议纪要，列出决议和行动项，然后起草项目启动通知发全部门。"
>
> 会议助理Agent提取决议与行动项→生成结构化纪要→公文撰写Agent根据纪要起草正式通知→主持Agent审核格式→输出定稿。全程不需要李主任手动整理和撰写。
