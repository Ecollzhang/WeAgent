# 演示视频录制方案（5分钟）

## 时间分配总表

| 阶段 | 时长 | 主题 | 功能点 |
|------|------|------|--------|
| 1 | 0:00-1:00 | 公共能力 | Agent管理、工具集、知识库、创建会话单/群聊、产物预览编辑 |
| 2 | 1:00-2:15 | RD 领域业务 | 项目、需求、缺陷、迭代、甘特图、代码仓库、审查、构建 |
| 3 | 2:15-3:50 | Agent 对话 × RD | 对话控制领域 → 卡片上屏 → 详情联动 → 审查修复 → 触发构建 |
| 4 | 3:50-5:00 | 多领域隔离 | edu/office 领域切换、侧边栏隔离、子角色、灰度控制 |

---

## 阶段 1：公共能力（0:00-1:00，60s）

### 1.1 登录 + Agent 管理（0:00-0:20）
1. 登录页轮播图（三大领域 + 多Agent协作），登录
2. 进入 Agent 管理页：左侧分类树（编程/测试/设计/文档/数据分析，有数量徽标）、右侧 Agent 卡片（头像、适配器标签 Claude/Codex、能力标签）
3. 拖拽一个 Agent 到另一个分类，排序更新

### 1.2 工具集（0:20-0:30）
1. 打开工具集页面：左侧分类栏 Skill/MCP/Plugin/Tool，切换 tab
2. 点开一个 Skill：概览 tab（权限声明、工具定义表）、文件 tab（SKILL.md）、安全审计 tab（风险等级/风险项）
3. 展示导入向导入口

### 1.3 知识库（0:30-0:42）
1. 打开知识库页面，领域 tab（all/rd/edu/office）
2. 文档列表：名称、来源标签、文件类型、分块数、状态（processing/ready）
3. 点开语义搜索测试面板 → 输入查询 → 结果列表（相关度% + 来源文档）
4. RAG 服务状态标识

### 1.4 创建会话 + 单/群聊 + 产物编辑（0:42-1:00）
1. 回到聊天页，点 "+" 打开新建会话弹窗
2. 单聊：勾选 1 个 Agent → 标题自动生成 → 标签"单聊"
3. 群聊：勾选 3 个 Agent → 标题自动生成 → 标签"群聊"、头像预览
4. 勾选"智能研发"服务 → 项目下拉出现 → 选项目
5. 创建完成，展示聊天界面
6. 底部 tab 依次切换：Agent 配置（system_prompt/skill/开关）、产物（预览服务列表、运行/停止操作）、日志（stdout/stderr）
7. 点开产物 tab 某个预览 → 编辑/查看

---

## 阶段 2：RD 领域业务（1:00-2:15，75s）

### 2.1 项目管理（1:00-1:15）
1. 侧边栏进入 RD 项目管理页，卡片网格（技术栈标签、完成度进度条、统计数字）
2. 点击"教学管理系统" → 概览 tab：技术卡片、统计数字（需求/缺陷/迭代/成员数）、当前迭代面板

### 2.2 需求 + 缺陷（1:15-1:35）
1. 需求 tab：层级表格（父需求+子需求）、列选择弹窗、行内编辑（标题/优先级/状态）、多选批量移入迭代
2. 点击进入需求详情页：Markdown 描述、工作流进度卡（5 阶段可点击）、子需求列表、AssigneeSelector（多角色）、评论
3. 切回项目，缺陷 tab：同样表格操作
4. 点击进入缺陷详情页：问题描述、关联需求（可添加/删除）、修复进度（分支和 commits）

### 2.3 迭代 + 甘特图（1:35-1:50）
1. 迭代 tab：迭代卡片（日期范围、Markdown 目标、进度条、需求/缺陷看板预览）
2. 甘特图 tab：月视图、需求横道、今日红线、周末底色、点击跳转详情

### 2.4 代码仓库 + 审查 + 构建（1:50-2:15）
1. 代码仓库 tab：GitHub OAuth 连接 → 关联仓库 → 文件树浏览（搜索、拖拽宽度）→ 代码查看器（暗色主题、语法高亮、Markdown 预览）
2. 打开代码审查页 `/reviews`：审查卡片（SVG 评分圆环、四维度得分条、问题统计）
3. 打开构建页 `/builds`：构建卡片（状态色条、步骤进度、GitHub Actions 标签）

## 阶段 3：Agent 对话 × RD（2:15-3:50，95s）

### 3.1 项目 → 对话（2:15-2:30）
1. 回到项目详情，点击顶部"新建对话"
2. 自动跳转聊天页 → **弹窗自动打开、RD 已勾选、项目已预填**
3. 选 2 个 Agent，创建群聊

### 3.2 Agent 查询需求 + 缺陷（2:30-3:05）
1. 发送："列出这个项目所有高优先级的需求"
2. Agent 调 RD API → 逐条上报 `requirement_card`
3. **连续多张同类卡片自动折叠分组**（标题栏"需求 5" + 展开/折叠箭头）
4. 展开分组，卡片展示：标题、优先级标签（p0红/p1橙）、状态、负责人
5. 点一张 → 跳转需求详情页
6. 切回聊天，发送："有哪些待处理的缺陷？" → `bug_card` 列表
7. 点一张 → 跳转缺陷详情，展示"创建修复分支" → 自动生成分支名并创建到 GitHub

### 3.3 Agent 查询迭代 + 项目（3:05-3:20）
1. 发送："当前有哪些迭代？" → `iteration_card`（日期范围、进度%）
2. 点迭代卡片 → 跳转项目迭代 tab 定位
3. 发送："项目概览" → `project_card`（项目名、描述、需求/缺陷统计数）

### 3.4 审查修复 + 构建触发（3:20-3:50）
1. 回到代码审查详情 → 问题卡片（严重度、文件:行号、before/after 对比、修复建议）
2. 点"一键修复" → 后台创建 GitHub 修复分支
3. 进入构建页 → 触发构建（选仓库→选Workflow→选分支→触发）
4. 详情侧边面板：步骤时间线（名称/耗时/可展开日志）、产物可下载

---

## 阶段 4：多领域隔离 + edu/office（3:50-5:00，70s）

### 4.1 教育领域（3:50-4:15）
1. 点工作空间切换器 → 选择"智慧教育"
2. 侧边栏自动切换：课程管理、作业系统、学生画像、成绩管理、教学资源
3. 创建新空间：选择"智慧教育" → **子角色下拉"教师"/"学生"** → 教师端 5 项导航 vs 学生端 4 项
4. Agent 管理页切到"课程设计师"分类（edu 专属 Agent + PPT生成器/题库引擎）
5. 新建会话 → 服务中"智慧教育"可选（端口 5102 已注册）

### 4.2 办公领域 + 灰度（4:15-5:00）
1. 切换到"智慧办公"空间 → 侧边栏变为：公文管理、会议管理、审批流程、报表服务、日程管理
2. Agent 管理页切到"公文撰写助手"分类（office 专属 Agent + 公文模板引擎）
3. 打开灰度管理页 `/admin/grayscale`，四个 tab 公共/rd/edu/office
4. 公共 tab 展示跨领域配置（`domains` JSON 字段控制生效范围）
5. 关闭教育领域"课程管理"侧边栏 → 保存 → 切回教育空间 → 导航消失
6. 重新开启 → 恢复，每个领域 UI 独立可控
