# 代码仓库实现方案（修订版：GitHub 集成）

## 核心思路

**不托管代码，只做信息聚合。** 用户的代码永远在 GitHub，我们通过 GitHub API 读取提交记录、分支、文件树，并且可以代表用户创建分支。用户正常在本地写代码 `git push`，平台自动同步展示。

```
用户本地 IDE → git push → GitHub ←── GitHub API ──→ 我们的平台 (只读+分支创建)
                                ↑                         │
                                └── OAuth 授权 ───────────┘
```

---

## 1. 授权流程

### OAuth App 配置

在 GitHub Settings → Developer settings → OAuth Apps 注册：

```
Application name: WeAgent
Homepage URL:     http://localhost:8080
Callback URL:     http://localhost:5101/api/rd/github/callback
```

### 用户授权

```
1. 用户进入 "代码仓库" Tab → 点击 "连接 GitHub"
2. 跳转 GitHub 授权页:
   https://github.com/login/oauth/authorize?client_id=xxx&scope=repo,read:org
3. 用户同意授权
4. GitHub 回调 → 后端拿 authorization code 换 access token
5. 加密存储 token 到 DB
6. 用户选择要关联的仓库
```

### 需要的 GitHub API 权限 (scopes)

| 权限 | 用途 |
|---|---|
| `repo` | 读写仓库（读提交、读文件、创建分支） |
| `read:org` | 读取组织仓库列表（可选） |

## 2. 数据库模型

```python
class RdGithubToken(db.Model):
    """GitHub OAuth Token"""
    __tablename__ = 'rd_github_tokens'

    id            = Column(String(36), primary_key=True)
    user_id       = Column(String(36), index=True)        # 平台用户ID
    github_user   = Column(String(100))                   # GitHub 用户名
    access_token  = Column(Text)                          # 加密存储
    token_type    = Column(String(50), default='bearer')
    scopes        = Column(String(500))                   # 授权的权限范围
    expires_at    = Column(DateTime)
    created_at    = Column(DateTime, server_default=now())

class RdRepo(db.Model):
    """关联的 GitHub 仓库 (元数据)"""
    __tablename__ = 'rd_repos'

    id            = Column(String(36), primary_key=True)
    project_id    = Column(String(36), ForeignKey, index=True)
    github_id     = Column(BigInteger)                    # GitHub repo ID
    owner         = Column(String(200))                   # 仓库拥有者 (user/org)
    repo_name     = Column(String(200))                   # 仓库名
    full_name     = Column(String(400))                   # owner/repo
    description   = Column(Text)
    default_branch= Column(String(100), default='main')
    language      = Column(String(50))
    html_url      = Column(String(500))                   # GitHub 页面链接
    clone_url     = Column(String(500))
    private       = Column(Boolean, default=False)
    status        = Column(Enum('active','archived'), default='active')
    synced_at     = Column(DateTime)                      # 最后同步时间
    created_at    = Column(DateTime, server_default=now())
```

**不再需要**：本地裸仓、GitPython、文件内容存储、worktree 操作。

## 3. GitHub API 操作封装

```python
import requests

GITHUB_API = 'https://api.github.com'

class GitHubService:

    def __init__(self, access_token):
        self.token = access_token
        self.headers = {
            'Authorization': f'Bearer {access_token}',
            'Accept': 'application/vnd.github+json',
            'X-GitHub-Api-Version': '2022-11-28',
        }

    def _get(self, path, params=None):
        return requests.get(f'{GITHUB_API}{path}', headers=self.headers,
                           params=params).json()

    def _post(self, path, json=None):
        return requests.post(f'{GITHUB_API}{path}', headers=self.headers,
                            json=json).json()

    # ── 仓库 ──
    def list_user_repos(self, page=1, per_page=100):
        """获取用户有权限的所有仓库"""
        return self._get('/user/repos', {
            'per_page': per_page, 'page': page,
            'sort': 'updated', 'type': 'owner'
        })

    def get_repo(self, owner, repo):
        """获取单个仓库信息"""
        return self._get(f'/repos/{owner}/{repo}')

    # ── 分支 ──
    def list_branches(self, owner, repo):
        return self._get(f'/repos/{owner}/{repo}/branches')

    def get_branch(self, owner, repo, branch):
        return self._get(f'/repos/{owner}/{repo}/branches/{branch}')

    def create_branch(self, owner, repo, name, from_branch='main'):
        """创建分支：先拿 from_branch 的 SHA，再创建"""
        base = self.get_branch(owner, repo, from_branch)
        sha = base['commit']['sha']
        return self._post(f'/repos/{owner}/{repo}/git/refs', {
            'ref': f'refs/heads/{name}',
            'sha': sha,
        })

    # ── 提交记录 ──
    def list_commits(self, owner, repo, branch='main', per_page=30):
        return self._get(f'/repos/{owner}/{repo}/commits', {
            'sha': branch,
            'per_page': per_page,
        })

    def get_commit(self, owner, repo, sha):
        return self._get(f'/repos/{owner}/{repo}/commits/{sha}')

    # ── 文件树 ──
    def get_tree(self, owner, repo, branch='main', path=''):
        """递归获取文件树"""
        # 先获取分支最新 commit 的 tree SHA
        branch_data = self.get_branch(owner, repo, branch)
        tree_sha = branch_data['commit']['commit']['tree']['sha']
        # 如果有子路径，先获取子树
        if path:
            resp = requests.get(
                f'{GITHUB_API}/repos/{owner}/{repo}/contents/{path}',
                headers=self.headers,
                params={'ref': branch}
            ).json()
            return resp  # GitHub contents API 直接返回文件/目录列表
        # 根目录用 git/trees 递归
        resp = requests.get(
            f'{GITHUB_API}/repos/{owner}/{repo}/git/trees/{tree_sha}',
            headers=self.headers,
            params={'recursive': '1'}
        ).json()
        return resp.get('tree', [])

    # ── 文件内容 ──
    def get_file_content(self, owner, repo, path, branch='main'):
        resp = requests.get(
            f'{GITHUB_API}/repos/{owner}/{repo}/contents/{path}',
            headers=self.headers,
            params={'ref': branch}
        ).json()
        if resp.get('encoding') == 'base64':
            import base64
            return base64.b64decode(resp['content']).decode('utf-8')
        return None

    # ── Pull Request (额外收益) ──
    def list_pull_requests(self, owner, repo, state='open'):
        return self._get(f'/repos/{owner}/{repo}/pulls', {'state': state})
```

## 4. API 接口 (我们的后端)

路由前缀 `/api/rd`

### GitHub 授权

| 方法 | 端点 | 说明 |
|---|---|---|
| `GET` | `/github/auth-url` | 获取 GitHub OAuth 授权 URL |
| `GET` | `/github/callback` | OAuth 回调，拿 code 换 token |
| `GET` | `/github/status` | 检查当前用户是否已授权 |
| `DELETE` | `/github/revoke` | 撤销授权 |

### 仓库管理

| 方法 | 端点 | 说明 |
|---|---|---|
| `GET` | `/github/repos` | 获取用户 GitHub 仓库列表（用于选择关联） |
| `POST` | `/projects/:id/repos` | 关联一个 GitHub 仓库到项目 |
| `GET` | `/projects/:id/repos` | 获取项目已关联的仓库列表 |
| `DELETE` | `/projects/:id/repos/:repo_id` | 取消关联 |

### 代码数据（通过 GitHub API 代理）

| 方法 | 端点 | 说明 |
|---|---|---|
| `GET` | `/repos/:id/branches` | 分支列表 |
| `POST` | `/repos/:id/branches` | 创建分支 |
| `GET` | `/repos/:id/commits?branch=` | 提交记录 |
| `GET` | `/repos/:id/tree?branch=&path=` | 文件树 |
| `GET` | `/repos/:id/file?branch=&path=` | 文件内容 |
| `GET` | `/repos/:id/pulls?state=` | Pull Request 列表 |

## 5. 用户操作流程

### 首次使用

```
1. 进入项目 → 代码仓库 Tab
2. 点击 "连接 GitHub"
3. 跳转 GitHub 授权 → 同意
4. 回调后显示用户的 GitHub 仓库列表
5. 勾选要关联的仓库 → 确认
6. 平台自动拉取仓库信息并展示
```

### 日常使用

```
用户本地 → git commit → git push → GitHub
                                        ↓
平台自动/定时同步 ← GitHub API ←── 仓库首页显示最新提交
                                        ↓
                            分支列表、文件树、提交历史 实时可查
```

### 创建分支

```
平台 → POST /repos/:id/branches { name: "feature/xxx" }
     → GitHubService.create_branch()
     → GitHub API 创建新分支
     → 用户本地 git fetch 即可看到
```

## 8. 优势总结

| 对比 | 自建裸仓方案 | GitHub 集成方案 |
|---|---|---|
| 代码存在哪 | 我们服务器 | GitHub（用户自己的） |
| 用户怎么开发 | 在线编辑器 / AI | 本地 IDE，正常 git workflow |
| 运维成本 | 磁盘、备份、权限 | 零 |
| 安全性 | 我们负责 | GitHub 负责 |
| PR/Review | 需要自建 | GitHub 原生支持 |
| AI 能写代码吗 | 可以（在线编辑） | 可以（AI → GitHub API → PR） |
| 用户接受度 | 低（又一个代码平台） | 高（不改变现有习惯） |

## 9. 补充：AI Agent 写代码

即使用户代码在 GitHub，AI Agent 依然可以参与开发：

```
用户在聊天中说: "帮我在 weagent-api 仓库创建 feature/health 分支，
                 并写一个 /health 健康检查接口"

AI Agent 执行:
1. GitHubService.create_branch('ecollzhang', 'weagent-api', 'feature/health')
2. GitHubService.get_file_content(...)  // 读取现有文件了解代码风格
3. 在回答中给出完整代码
4. 或者在沙箱中写好代码 → 通过 GitHub API 创建 commit → 创建 PR
```

这样 AI 写代码 → 提交到 GitHub → 人类 review PR → 合并，形成完整的 AI 辅助开发工作流。
