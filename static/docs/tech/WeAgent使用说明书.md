# WeAgent 使用说明书

## 1. 产品简介

WeAgent 是一个面向复杂任务执行的 AI Agent 工作平台。用户可以通过单 Agent 独立完成明确任务，也可以通过多 Agent 协作处理更复杂的需求。平台支持会话管理、Agent 配置、Adapter 适配器切换、容器执行、多类型产物预览编辑、工作流展示以及 Web / 桌面端 / Android 多端使用。

WeAgent 的核心目标是帮助用户把一个任务从“提出需求”推进到“执行完成并收获产物”。这些产物可以是文件、表格、代码、HTML 页面、图片、Diff、日志或工作流图。

## 2. 快速开始

### 2.1 登录平台

打开 WeAgent 后，用户可以使用已有账号登录。如果还没有账号，可以先进入注册页面创建账号。

[图片预留：登录页面截图]

操作步骤：

1. 打开 WeAgent。
2. 输入用户名或邮箱。
3. 输入密码。
4. 点击登录。
5. 登录成功后进入会话页面。

### 2.2 配置模型

首次使用前，建议先完成模型配置。模型配置决定 Agent 调用哪个模型服务。

[图片预留：模型设置页面截图]

操作步骤：

1. 进入左侧菜单中的“设置”。
2. 选择“模型设置”。
3. 填写 API Key。
4. 选择模型名称，或填写自定义模型。
5. 填写 API Base URL。
6. 设置 Temperature 和最大 Token 数。
7. 点击保存。

完成模型配置后，可以先发送一条简单消息测试模型是否可用。

## 3. 完成第一个单 Agent 任务

单 Agent 任务适合目标明确、职责单一的场景，例如生成 README、分析代码结构、修改一个前端页面、整理文档等。

[图片预留：单 Agent 新建会话截图]

### 3.1 新建单 Agent 会话

操作步骤：

1. 进入“对话”页面。
2. 点击新建会话。
3. 选择“单 Agent”。
4. 选择一个适合任务的 Agent。
5. 确认创建会话。

### 3.2 输入任务

在输入框中描述你希望 Agent 完成的任务。任务描述越清楚，Agent 的执行结果通常越稳定。

示例：

```text
请帮我阅读当前项目结构，并生成一份 README 初稿。
```

或：

```text
请分析这个前端页面的布局问题，并给出修改建议。
```

[图片预留：单 Agent 会话执行过程截图]

### 3.3 查看执行结果

Agent 执行任务时，页面中会展示：

- Agent 回复内容
- 当前进度
- 进度历史
- 执行结果
- Raw Output
- 生成的产物

如果任务生成了文件、表格、代码或图片，可以在消息产物区域或产物抽屉中查看。

[图片预留：单 Agent 结果与产物截图]

## 4. 完成第一个多 Agent 协作任务

多 Agent 协作适合复杂任务，例如一个任务需要产品分析、前端实现、文档生成、代码审查等多个角色共同完成。

[图片预留：多 Agent 新建会话截图]

### 4.1 新建多 Agent 会话

操作步骤：

1. 进入“对话”页面。
2. 点击新建会话。
3. 选择“多 Agent”。
4. 选择多个参与 Agent。
5. 创建会话。

多 Agent 会话中通常会包含一个主持人 Agent。主持人 Agent 负责理解用户需求、拆解任务、安排成员执行并汇总结果。

### 4.2 输入协作任务

示例：

```text
请帮我设计一个产品使用手册页面，先由主持人拆解任务，再让前端 Agent 负责页面结构和样式，文档 Agent 负责内容整理。
```

[图片预留：主持人 Agent 拆解任务截图]

### 4.3 查看任务分配与执行过程

在多 Agent 会话中，可以查看：

- 主持人 Agent 的任务拆解
- 各个 Agent 的执行结果
- 多 Agent 协作进度
- 工作流图
- 汇总结果
- 生成产物

[图片预留：多 Agent 协作消息截图]

### 4.4 查看工作流图

如果会话生成了工作流图，可以点击工作流产物进行预览。工作流图用于展示主持人 Agent 如何分配任务，以及多个 Agent 之间的执行关系。

## 5. Agent 配置

WeAgent 支持两类 Agent 配置：全局 Agent 配置和会话级 Agent 配置。

### 5.1 全局 Agent 配置

全局 Agent 配置用于维护平台中的 Agent 基础信息。新建会话时选择的 Agent，默认使用这里的配置。

[图片预留：我的 Agent 页面截图]

可配置内容包括：

- Agent 名称
- Agent 头像和颜色
- 能力标签
- 系统提示词
- Skill
- 工具集
- 底层 Adapter

### 5.2 会话级 Agent 配置

会话级 Agent 配置只对当前会话生效，不会修改全局 Agent。它适合临时调整某个 Agent 在当前任务中的工作方式。

[图片预留：会话级 Agent 配置截图]

适合使用会话级配置的场景：

- 当前任务需要 Agent 更严格遵循某种流程。
- 当前任务只关注某个模块。
- 当前任务需要临时调整 Skill。
- 当前任务需要切换工具或底层 Adapter。

## 6. Adapter 适配器

WeAgent 实现了 Adapter 适配器能力，用于接入不同的底层执行引擎。目前平台已支持 Codex、Claude Code、OpenCode 等接入方式。

每个 Agent 可以根据任务需要切换底层 Adapter。例如：

- 代码实现类任务可以选择更适合编码执行的 Adapter。
- 文档整理类任务可以选择更适合文本生成的 Adapter。
- 不同 Agent 可以使用不同底层支持，以适配不同任务类型。

## 11. 常见问题

### 11.1 登录失败怎么办？

请确认账号密码是否正确，并检查后端服务是否正常启动。

### 11.2 模型调用失败怎么办？

请检查模型配置中的 API Key、Base URL、模型名称是否正确。

### 11.3 创建会话失败怎么办？

请检查后端服务、数据库和沙箱容器是否正常。如果错误提示与 Docker 镜像有关，需要先构建或加载沙箱镜像。

### 11.4 文件或图片无法访问怎么办？

请确认文件路径是否存在、后端地址是否正确、容器是否仍在运行。Android 端还需要确认设备是否可以访问局域网后端地址。

### 11.5 Agent 没有按预期执行怎么办？

可以检查 Agent 的能力标签、系统提示词、Skill 和 Adapter 配置。对于当前会话中的特殊任务，可以使用会话级 Agent 配置临时调整。

## 12. 推荐使用方式

为了获得更稳定的执行效果，建议按以下方式使用 WeAgent：

1. 先明确任务目标。
2. 说明约束条件和验收标准。
3. 简单任务使用单 Agent。
4. 复杂任务使用多 Agent。
5. 需要临时调整行为时使用会话级 Agent 配置。
6. 任务完成后查看产物抽屉。
7. 对重要会话进行收藏。
8. 对生成的文件、表格、代码和 Diff 进行复查。

推荐提示词示例：

```text
请先理解我的需求，列出你的执行计划，然后再开始执行。完成后请说明生成了哪些产物，以及我应该如何查看。
```

```text
这是一个多 Agent 协作任务，请主持人先拆解任务，说明每个 Agent 的职责，再安排执行。
```

```text
请基于当前会话产物继续修改，并展示修改前后的 Diff。
```
