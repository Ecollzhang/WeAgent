# WeAgent 开发迭代 & 版本线

## v1.0.0：单 Agent 与 Docker 沙箱基础

实现功能：
- 建立单 Agent 任务执行基础链路。
- 支持 Agent 在 Docker 沙箱环境中执行任务。
- 补充 Docker 环境部署说明。
- 支持沙箱镜像加载与基础运行流程。
- 初步形成"用户发起任务 → Agent 执行 → 返回结果"的核心流程。

## v1.0.1：多 Agent 协作与规范化消息展示

实现功能：
- 支持多 Agent 参与同一会话。
- 引入主持人 Agent，用于理解任务、拆解任务和调度成员。
- 支持 Agent 消息的规范化展示。
- 支持进度、结果、Raw Output、产物等消息结构。
- 初步形成多 Agent 协作任务处理能力。

## v1.0.2：Adapter 适配器接入

实现功能：
- 实现 Claude Code / Codex / OpenCode 适配器。
- 新增 Codex Agent。
- 新增 OpenCode Agent。
- 支持不同 Agent 切换底层执行支持。
- 完成相关 Provider 适配器测试。
- 提升平台对不同 AI Coding 执行引擎的扩展能力。

## v1.0.3：会话参与者与消息时间修复

实现功能：
- 修复会话参与者计数错误。
- 修复消息时间显示异常。
- 优化会话列表和消息展示的数据准确性。
- 提升会话基础体验稳定性。

## v1.0.4：@ 指定 Agent 工作

实现功能：
- 支持在会话中通过 @ 指定某个 Agent 执行任务。
- 提升多 Agent 协作中的调度可控性。
- 用户可以直接指定目标 Agent，而不是完全依赖主持人自动选择。
- 优化多 Agent 场景下的任务分配体验。

## v1.0.5：容器服务暴露与 Service 消息

实现功能：
- 新增 type=service 类型消息。
- 增加启动容器服务的脚本。
- 支持访问容器中启动的服务。
- 后端端口调整到 5002。
- 为 HTML 页面预览、容器服务访问等能力打基础。

## v1.0.6：桌面端支持

实现功能：
- 新增 Electron 桌面端。
- 桌面端支持连接外部后端。
- 桌面端迁移登录、注册、会话、Agent、设置等主要功能。
- 支持桌面端消息展示、产物查看、文件上传、容器文件访问等能力。
- 支持桌面应用打包，应用名为 WeAgent。

## v1.0.7：Android 端支持

实现功能：
- 基于 Capacitor + Vue 实现 Android 端。
- 支持 Android 登录、注册。
- 支持 Android 会话列表和会话详情。
- 支持 Android Agent 页面。
- 支持 Android 个人设置页面。
- 支持局域网后端连接测试。
- 初步完成移动端主要功能迁移。

## v1.0.8：收藏、历史与搜索

实现功能：
- 移除原"沙箱测试"入口。
- 新增"我的收藏"页面。
- 支持会话收藏和取消收藏。
- 收藏会话可进入对应聊天。
- 支持会话详情右上角搜索。
- 搜索后可定位到指定消息位置。
- 支持对话详细历史。
- 历史中展示用户问题标题，点击后跳转到对应消息。

## v1.0.9：会话级 Agent 配置、产物、日志与工作流入口

实现功能：
- 在输入框上方新增快捷入口：对话、智能体配置、产物、日志、工作流。
- 支持会话级 Agent 配置，只在当前会话生效，不影响全局 Agent。
- 产物抽屉展示当前会话所有产物，支持分类展示与文件、表格等操作。
- 日志侧栏展示容器执行日志。
- 工作流入口打开全屏弹窗。

## v1.1.0：自定义工作流图

实现功能：
- 支持多 Agent 自定义工作流图。
- 主持人 Agent 可生成任务分配计划。
- 工作流以图形方式展示多 Agent 协作路径。
- 单 Agent 场景下支持工作步骤指导。
- 消息中的工作流产物支持预览。
- 强化复杂任务的过程可视化能力。

## v1.1.1：使用手册、产品介绍与文档体系完善

实现功能：
- 在设置中新增"关于我们"入口。
- 新增使用手册页面、产品介绍页面、迭代历程页面。
- 使用手册补充快速开始、单 Agent、多 Agent、Agent 配置、产物与文件等说明。
- 产品介绍补充平台定位、核心能力、功能轮播图。
- 迭代历程整理 v1.0.0 到 v1.1.1 的版本线。
- 完善项目 README 和多级文档入口。

## v1.1.2：多领域基座、RAG 服务与灰度控制

实现功能：
- 搭建"工作空间 + 领域隔离"架构，不同领域独立配置 Agent 与功能。
- 完成 RAG（检索增强生成）服务搭建，支持文档解析、向量化存储与语义检索。
- 实现灰度控制系统，支持按领域按功能灵活开启/关闭特性。
- 领域服务与聊天会话打通，点击领域快捷入口直接创建对话。
- 支持多标签页多账号同时登录测试（登录态迁移至 sessionStorage）。

## v1.1.3：智能研发领域

实现功能：
- 搭建智能研发领域完整系统，涵盖项目管理、需求追踪、迭代规划、缺陷管理。
- 实现项目 CRUD、文件管理、项目上下文接口。
- 支持甘特图可视化展示迭代与需求的时间线。
- 新增代码仓库管理，支持 GitHub OAuth 授权与仓库关联。
- 实现代码审查引擎，支持安全、规范、逻辑、性能四维度自动审查。
- 实现 CI/CD 构建管理，对接 GitHub Actions 触发与状态同步。
- Agent 可感知项目上下文，主动推送需求卡片、缺陷卡片、迭代卡片等结构化消息。
- 新增 Team 页签支持项目成员管理与角色分配。
- 支持项目详情 Tab 记忆、迭代 Markdown 渲染、需求子任务层级等体验优化。

## v1.2.0：智慧教育领域

实现功能：
- 搭建智慧教育领域完整系统，支持教师、学生双角色独立工作空间。
- 实现自定义课程体系搭建，支持学科课程创建与内容编排。
- 支持 AI 辅助作业批改，学生通过引导式对话获取一对一辅导反馈。
- 实现知识点薄弱项智能诊断，自动生成学情报告与学习建议。
- 支持课件导入导出，Agent 辅助生成可编辑的教学课件与演示文稿。
- 实现班级花名册管理与课程成员邀请机制。
- 支持版本化教学循环，课件与作业按版本独立发布与回溯。
- 打通教育沙箱运行时，Agent 可安全访问课程资源与学习产物。
- 实现角色感知导航，教师与学生在同一平台获得差异化功能视图。

## v1.2.1：智慧办公领域

实现功能：
- 搭建智慧办公领域系统，覆盖会议管理、任务派发、公文审批与组织协同四大场景。
- 会议管理：支持会议创建、参会确认、主持人置顶、会后维护弹窗，Agent 自动生成会议纪要。
- 任务管理：支持行动项拆解、责任人指派、进度跟踪与卡片化展示。
- 公文审批：支持直属领导并行审批与部门经理逐级审批，公文台双栏布局直观呈现流转状态。
- 组织协同：拆分组织关系与团队任务两个子模块，支持组织架构管理与跨团队任务分配。
- Agent 接入办公服务沙箱，可自动生成纪要、跟踪任务闭环、辅助审批流转。

## v1.2.2：三领域融合与平台收束

实现功能：
- 智能研发、智慧教育、智慧办公三领域合并至主分支。
- 统一侧边栏导航，各领域按灰度配置动态显示入口。
- 领域空间支持创建与删除，用户可灵活管理多个工作空间。
- 完善领域间的会话隔离与会话级服务配置。
- 统一平台产品介绍、平台定位与核心能力描述。
