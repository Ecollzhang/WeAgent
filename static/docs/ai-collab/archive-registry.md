## 2. 使用规则

- `sessions/`、`archive/`、`summaries/` 中的归档人或负责人必须来自本 registry。
- 新增成员前，先在这里补充成员名，再创建对应归档文件。
- 当前 why 负责 factory 兼容 Codex + Claude Code gateway 方向。
- 当前 zsw 负责 agent 执行环境与 workspace sandbox 方向。
- 当前 zby 负责后端信息数据存储与前端展示方向。
