## 4. 归档提炼

从原始对话中提炼出的有效内容：

- schema 的核心目的应是“聊天后归档与沉淀”，而不是模拟成熟项目的完整规范体系
- session 应以“记录”为主，保持短小，避免承担过重的项目管理职责
- 当前项目进展应使用负责人打头的结构，而不是使用 `任务 1 / T1` 之类编号
- session 中“当前项目进展”与“关联任务”可以合并，直接记录 `对应负责人 / 对应任务方向`
- `未解决问题` 与 `下一步行动` 合并成 `未解决问题 / 后续建议` 更适合当前项目阶段
- 每次归档默认先有 session，archive 只在内容具备长期复用价值时补充
